Revision History: Modifying Kernel Boot Parameters

2026-09-04

  • Corrected the temporary modification procedure and the boot-failure recovery procedure to state that the GRUB 2 menu appears by default with a visible countdown, replacing the earlier claim that it is hidden by default and requires pressing Esc to reveal.

  • Added a note that transactional-update run snapshots do not stack without a reboot in between.

2026-08-26

  • Updated the permanent kernel boot parameter procedure, replacing YaST Control Center Boot Loader instructions with the update-bootloader command, since SLE for NVIDIA 16 no longer includes YaST.

  • Updated the security configuration information to reflect that SLE for NVIDIA 16 uses SELinux by default instead of AppArmor.

  • Updated the linuxrc comparison to reflect that linuxrc no longer exists on SLE for NVIDIA 16; early-boot parameters formerly associated with it are now documented as ordinary kernel boot parameters handled by dracut.

  • Corrected the boot menu procedure to confirm that both F10 and Ctrl–X boot the edited GRUB 2 entry, and clarified that recovering from a boot failure means selecting the (recovery mode) entry under Advanced options for SLE for NVIDIA 16.1, not a separate recovery mode.

  • Added the physical or remote console access requirement for temporarily modifying kernel boot parameters and for recovering from a boot failure; neither works over SSH.

  • Added instructions for revealing the GRUB 2 boot menu on systems where it is hidden by default.

  • Added a recommendation to test a parameter temporarily before making it permanent.

  • Added a recovery path for a boot failure when no pre-modification backup exists.
